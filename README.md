📈 Dynamic Regime Trading Dashboard

A real-time Options Trading Dashboard and Strategy Engine powered by Dash, Plotly, and the Angel One SmartAPI.

## 🚀 Features
* **Real-time Charting:** Live Candlestick charts integrated with VWAP, Bollinger Bands, RSI, and MACD.
* **Regime Switching Engine:** Automatically classifies market state (Bull, Bear, Sideways) using ADX and routes trading logic accordingly.
* **Options & P&L Calculator:** Tracks simulated 1-day expiry Iron Condors and ATM Directional option signals.
